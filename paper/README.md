# Paper

Manuscript sources: `main.tex`, `sections/`, `refs.bib`, and
`references/verified_sources.json`. Rules that `scripts/check_manuscript.py`
will enforce once the manuscript opens:

1. No em-dash, en-dash, or curly quote anywhere in the TeX sources; no word
   from `tools/banned_words.txt`.
2. Every citation key in `refs.bib` has a record in
   `references/verified_sources.json` naming the primary publication page or
   official documentation it was verified against and the date.
3. Every number in the text is read from `analysis/generated/` through a
   generated macro or table file; no measured number is typed by hand.
4. Every figure exists under `figures/` and is regenerated by
   `scripts/make_figures.py`.
5. Every experiment id cited in the text has a logbook entry and registry
   run.

The review copy is anonymized from these sources into a separate artifact
directory when a submission opens; this repository stays public.
